# Future research

This roadmap proposes extensions. It does not report experiments or authorize paid batches.

## Stronger identification of interaction effects

Add one-shot institutional descriptions, no-history and reset-memory controls, yoked histories, counterfactual event substitutions, randomized communication networks and neutral institutions with distinct vocabulary. Compare matched initial states and history exposure to separate label priors, mechanical opportunity, imitation and context-dependent behavioural change. Specify what would falsify each explanation before collecting data.

## Publication-oriented evaluation

Preregister endpoints, minimum meaningful effect, exclusions, stopping/censoring rules, sample sizes and a power analysis. Conduct enough independent complete seed/model blocks to estimate variability. Use hierarchical/cluster-aware models, sensitivity analyses for denominators and temporal trends, and correction for multiple exploratory endpoints. Evaluate coded proxies against blinded independent raters and publish disagreement, not only selected examples. Add randomized study execution order and controlled provider/model snapshot replication.

## Measurement development

Implement a separate blinded text-analysis pipeline for ambiguous communication, with model/rubric/version/cost logs, inter-rater reliability, calibration against human annotations and disagreement review. Redact experimental labels while acknowledging that institutional language can unblind raters. Do not inject analysis labels into agent context. Distinguish imposed restrictions from reasonable coordination, reciprocal sanctions, scope-weighted rule restrictiveness and inequitable outcomes from unfair motivations.

Add opportunity-normalized administrative rates, allocation inequality integrated over days, dispute/appeal resolution times, accepted-versus-fulfilled commitments, task burden distributions and network-level alliances. Graph measures should count observable exchange, not assume social bonds or internal affect. Stress-test the provisional three-action classification threshold and report robustness to alternatives.

## Environmental and software extensions

Make schedules operational, support enforceable typed resource-sharing agreements, alternative governance mechanisms, persistent task workload and audit-friendly institutional rule DSLs. Any new mechanic must remain identical across the four core conditions or become a separately labeled factor. Explore memory strategies, heterogeneous models, access visibility and personality distributions as controlled moderator studies.

Add compact incremental snapshots for very long studies, streaming exports, schema migrations, disk quotas, richer crash reconciliation with provider records, an account-side spending-cap integration and provider token-count preflights where supported. Add a dedicated analysis-only export with private text redaction and spreadsheet-safe CSV presentation. Current replay is snapshot based, single-process local execution; it does not automatically resume interrupted paid runs.

## Reporting boundaries

Publish raw/derived provenance with appropriate data review, precise model and protocol versions, failures and null effects. Do not describe mock trajectories as findings or extrapolate computational action proxies to consciousness, human suffering or human psychological mechanisms. Claims about emergence should remain conditional on intervention evidence and replication across prompt templates, institutions and models.
